# 网球原型 · 一键自动化测试

## 1. 在浏览器里一键跑（电脑 / 手机都行）
打开 `index.html` → 点顶部「🧪 一键自动化测试」（开始画面上也有）：
- **快速测试（约 1 分钟）**：4 个模式各实时跑 8 秒测帧率，再快速模拟几千拍算命中率、给调难度建议。
- **耗电测试（10 分钟）**：手机拔掉充电线、保持亮屏，机器人连续打 10 分钟，算每小时掉电 %。
  电量接口只有安卓 Chrome 支持；iPhone Safari 只能看「主线程占用」作为粗略参考。
- 跑完可以下载 JSON / CSV；测试结束后参数和模式会自动恢复，不影响正常玩。

## 2. 命令行一键跑（适合每次改完代码回归）
```bash
npm install && npx playwright install chromium
npm test                                  # 电脑 Chrome
npm test -- --device "Pixel 7" --cpu 4     # 手机屏幕 + CPU 降速 4 倍（模拟中端机）
```
结果写到 `./autotest-results/`（JSON + CSV + 截图）。有 FAIL 时退出码为 1，可以直接放进 CI。
也可以直接在网址后面加 `?autotest=quick&perfSec=8&n=120`（或 `?autotest=soak&soakMin=10`）自动开跑。

## 3. 检查项
| ID | 检查 | 通过标准 |
|---|---|---|
| PAUSE | 暂停后游戏时间不走 | Δt = 0 |
| DET | 同一随机种子跑两次结果完全一致（结果可复现） | 完全相同 |
| STAT | 统计自洽：计分板击球数 = 机器人挥中数，界内 ≤ 判定 ≤ 击球 | 0 组不一致 |
| EXPERT | 高手模拟玩家在默认参数下命中率 | ≥ 95% |
| FPS / LOW1 | 平均帧率 / 1% 低帧 | ≥ 55 / ≥ 30（低于为 WARN/FAIL） |
| JSERR | 测试中无 JS 报错 | 0 |

## 4. 命中率怎么来的
- **模拟玩家** 4 档（新手 / 普通 / 熟练 / 高手）：时机误差 75 / 50 / 30 / 15 ms，新手平均偏晚，站位误差和起步反应时间也不同。
  参数是估的，只适合比较「改参数之后变难还是变简单」。
- **真人记录**：关掉「自动演示」自己打时，每一拍（命中 / 太早 / 太晚 / 够不到、误差 ms、界内或出界、当时的判定窗口）
  自动存在本浏览器里，报告里按判定窗口分组显示，可导出 CSV。找几个人各打 5 分钟，再换个判定窗口打一轮，就能用真实数据定难度。
- 难度目标在代码 `TARGETS` 里（默认：新手 ≥55%、普通 75–90%、高手 ≥97%），按你的设计目标改。
